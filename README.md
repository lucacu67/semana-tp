# Semana-tp
Lucky Magnet es un prototipo de máquina de feria automatizada mediante Arduino, diseñado para recrear la experiencia de un juego de destreza de forma electrónica y precisa.

a continuación se dara una explicación breve del proyecto:

# ¿En qué consiste?
Una estructura motorizada controlada por joystick que desplaza un electroimán para descender, atrapar premios metálicos y elevarlos con éxito.

# ¿Cúal es su propósito?
Es una mini maquina de peluches que sea controlada por un Arduino. El jugador utilizara un joystick y boton para dirigir un carrito con un imán para que intenten conseguir un peluche. Planeamos que el carrito se mueva con poleas e hilo, mientras que rodamientos de patín para un desplazamiento suave. El Arduino controlará los motores, el joystick, el boton y cuando el iman tiene magnetismo para tomar y soltar premios
